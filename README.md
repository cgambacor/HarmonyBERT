# HarmonyBERT

Repositorio correspondiente al desarrollo de **HarmonyBERT**, una adaptación de MusicBERT para el aprendizaje de información armónica a partir de música simbólica.

## Contenido del repositorio

* **`analisis_Cojator_HarmonyBERT.ypynb`**
  Cuaderno para el análisis de las diferentes estrategias de enmascaramiento utilizadas.

* **`Evaluacion_del_modelo.ipynb`**
  Cuaderno para la evaluación del modelo y la obtención de las estadísticas correspondientes.

* **`mscx_to_nanobeat_local.py`**
  Script para el procesamiento de archivos MSCX a partir de corpus almacenados localmente.

* **`mscx_to_nanobeat_online.py`**
  Script para el procesamiento de archivos MSCX mediante la extracción de corpus disponibles en línea.

* **`normalize_harmony_lvl1.py`**
  Funciones de normalización de las anotaciones de armonía correspondientes al nivel 1.

* **`normalize_harmony_lvl2.py`**
  Funciones de normalización de las anotaciones de armonía correspondientes al nivel 2.

* **`train_harmonybert.py`**
  Script utilizado para el entrenamiento del modelo HarmonyBERT.

* **`harmonybert_model.py`**
  Implementación del modelo HarmonyBERT.
